# 疑惑

记录还没想清楚的问题。每个问题一个文件，避免不同话题纠缠在一起。

## 命名

`q-NNNN-短标题.md`，编号递增，例如 `q-0001-自研还是组装现有工具.md`。

## 模板

```markdown
# 问题

一句话说清要回答什么。

- 状态：开放
- 日期：YYYY-MM-DD
- 相关：

## 背景

为什么现在会冒出这个问题？触发它的事实是什么？

## 目前的倾向

我猜……（写下直觉，方便之后对照）

## 需要查证 / 验证

-
-

## 结论

想清楚后填写，必要时链接到 `docs/decisions/` 下的决断记录。
```
