# 技术决断（ADR）

凡是"以后可能有人问为什么"的选择，都记一条 Architecture Decision Record。

## 规则

- 编号递增，**不改号**；文件名为 `NNNN-短标题.md`。
- 已接受的决断不直接改写内容。改变主意时新写一条，并在旧条目状态里标注"被 NNNN 取代"。
- 一条决断只回答一个问题；想写"顺便也定了……"时，拆成两条。
- 背景里写事实（约束、数据、踩过的坑），不写立场。

## 状态

`提议中` → `已接受` / `已拒绝`；`已接受` 之后可能变为 `被 NNNN 取代`。
